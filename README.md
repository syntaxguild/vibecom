# Desk Companion Bot

เฟิร์มแวร์ C++ สำหรับ ESP32, Arduino Framework, PlatformIO และ Wokwi Simulator

![ภาพดวงตาจากโค้ด Adafruit GFX ของเฟิร์มแวร์](docs/eye-preview.png)

## เริ่มจำลองใน VS Code

1. เปิดโฟลเดอร์นี้ใน VS Code และติดตั้งส่วนเสริม **PlatformIO IDE** กับ **Wokwi Simulator** ตามคำแนะนำของ workspace
2. รอ PlatformIO ติดตั้งเครื่องมือให้เสร็จ แล้วกด **PlatformIO: Build** (เครื่องหมายถูกที่แถบล่าง) หรือรัน `pio run -e esp32dev` ใน PlatformIO terminal
3. กด `F1` → **Wokwi: Start Simulator** หาก Wokwi ขอเปิดใช้งาน license ให้ทำตามหน้าจอของส่วนเสริมก่อน
4. คลิก HC-SR04 แล้วเลื่อนค่า Distance เพื่อทดสอบ เริ่มต้นที่ 100 cm
5. กดปุ่มสีฟ้า **PET ME** ค้าง หรือใช้ปุ่ม `P` เมื่อโฟกัสอยู่ที่ Simulator เพื่อทดลองลูบหัว
6. ดูระยะทาง โหมด มุมเซอร์โว และ FPS ใน Serial Monitor ของ Wokwi ที่ 115200 baud

Wokwi ใช้ `.pio/build/esp32dev/firmware.bin` และ `firmware.elf` ซึ่งได้จากการ Build ต้อง Build ใหม่เมื่อแก้ไขโค้ด แล้วเริ่ม Simulator ใหม่

## พฤติกรรม

| โหมด / เงื่อนไข | ดวงตา OLED | เสียง / เซอร์โว |
| --- | --- | --- |
| Idle: มากกว่า 50 cm | ตาแคปซูลทึบ กลอกตามองรอบตัวแบบนุ่มนวล กะพริบแบบยุบแล้วเปิด | เงียบ คอขยับตามสายตาเล็กน้อย |
| Idle / Sleepy: ไม่มีปฏิสัมพันธ์เกิน 10 วินาที | ตาปรือครึ่งหนึ่ง มี Zzz ลอยขึ้น | เงียบ คอกลับ 90° |
| Happy: 15–50 cm รวมขอบทั้งสองด้าน | ตาโค้งยิ้ม หัวใจและดาวลอยข้างแก้ม | เมโลดี้ 8-bit พร้อมส่ายคออย่างนุ่มนวล |
| Angry: น้อยกว่า 15 cm | ตาถูกตัดขอบเป็นคิ้วขมวด สั่นเล็กน้อย มีเครื่องหมายตกใจ | เสียงเตือนรัว หันหนีไป 180° |
| Love: กดปุ่ม GPIO 4 มีลำดับความสำคัญสูงสุด | ตาหัวใจเต้นเบา ๆ ไฮไลต์วิ้งและแก้ม | เสียง purr/chirp พร้อมดุ๊กดิ๊กคอเบา ๆ |
| ไม่มี echo ภายใน 30 ms | กลับ Idle พร้อมรายงาน no echo | หยุดเสียงจากโหมดระยะทาง |

Love ค้างต่ออีก 1.2 วินาทีหลังปล่อยปุ่ม ปุ่มมี debounce 25 ms การขยับวัตถุห่างจากระยะอ้างอิงอย่างน้อย 4 cm จะปลุกจากอาการง่วง รวมถึงการเข้าใกล้ในระยะ 50 cm หรือการลูบหัว

## แอนิเมชันและการทำงานพร้อมกัน

วาด Procedural Animation ทุก 16,667 µs (เป้าหมาย 60 FPS) ด้วย `fillRoundRect`, `fillCircle`, `fillTriangle` และสีดำตัดขอบ มีจุดไฮไลต์สีขาวบนรอยเว้าสีดำเพื่อให้เห็นชัดบนจอขาวดำ ไม่มี `delay()`, `delayMicroseconds()` หรือ `pulseIn()` ในเฟิร์มแวร์

HC-SR04 เริ่มวัดทุก 80 ms และใช้ interrupt จับเวลา ECHO ส่วนปุ่ม เสียงโน้ตแบบเลื่อนความถี่ และการขยับคอมีตารางเวลาแยกกัน Buzzer ใช้ LEDC channel 14 / timer 3 ส่วน ESP32Servo จำกัดให้ใช้ timer 0 จึงไม่เปลี่ยนความถี่เซอร์โวขณะร้องเพลง

I²C ใช้ 400 kHz ตามปกติ การส่งภาพเต็ม 1,024 bytes ทุกเฟรมจะใช้เวลามากกว่า 23 ms จึงใช้บัฟเฟอร์ภาพที่กำลังส่งแยกจากภาพที่กำลังวาด และส่งเฉพาะช่วง pixel ที่เปลี่ยนไป ครั้งละไม่เกิน 120 bytes (ประมาณ 3 ms) ให้ loop กลับไปบริการอินพุตระหว่างช่วงส่งข้อมูล จังหวะ I²C แต่ละช่วงยังเป็น synchronous ตาม Wire API แต่ไม่มีการรอให้แอนิเมชันหรือเสียงเล่นจบ

Serial รายงาน `FPS draw` (อัตราสร้างภาพ) และ `OLED` (อัตราที่ส่งภาพเสร็จ) รวมทั้ง `skipped` (ภาพที่ถูกแทนด้วยภาพใหม่ก่อนเริ่มส่ง) ค่า OLED อาจต่ำกว่า 60 ขณะเปลี่ยนอารมณ์หรือเมื่อ Simulator ทำงานช้า จึงไม่ใช้ตัวเลขจังหวะ render อ้างเป็น FPS จริงของจอ

## การต่อวงจรจำลอง

| อุปกรณ์ | ขาอุปกรณ์ | ESP32 |
| --- | --- | --- |
| SSD1306 128×64 (0x3C) | SDA / SCL | GPIO 21 / GPIO 22 |
| SSD1306 | VCC / GND | 3V3 / GND |
| Servo | PWM | GPIO 18 |
| Servo | V+ / GND | 5V / GND |
| HC-SR04 | TRIG / ECHO | GPIO 5 / GPIO 19 |
| HC-SR04 | VCC / GND | 5V / GND |
| Buzzer | 2 (+) / 1 (-) | GPIO 25 / GND |
| PET ME pushbutton | 1.l / 2.l | GPIO 4 / GND (`INPUT_PULLUP`) |

สายแดงคือไฟเลี้ยง สายดำคือกราวด์ ส่วนสัญญาณใช้สีแยกกัน อุปกรณ์ทุกชิ้นต่อกราวด์ร่วมกับบอร์ด Buzzer และปุ่มแยกไว้คนละบริเวณกับเซนเซอร์และเซอร์โว

## เมื่อนำไปใช้กับฮาร์ดแวร์จริง

วงจรจำลองต่อ ECHO ตรงเข้า GPIO 19 ตามโมเดล Wokwi แต่ HC-SR04 จริงส่ง ECHO ระดับ 5V จึงต้องลดเหลือประมาณ 3.3V ก่อนเข้าขา ESP32 เช่น ECHO → ตัวต้านทาน 1 kΩ → GPIO 19 และ GPIO 19 → ตัวต้านทาน 2 kΩ → GND

เซอร์โวจริงควรใช้แหล่งจ่าย 5V ที่จ่ายกระแสพอสำหรับมอเตอร์ และต่อกราวด์ร่วมกับ ESP32 ปรับช่วง pulse ของ `neck.attach()` และมุมหลบใน `serviceNeck()` ให้ตรงกับขอบเขตกลไกจริง เสียงใช้ passive piezo buzzer; หากใช้ลำโพงหรือ buzzer กินกระแสสูง ต้องมีวงจรขับที่เหมาะสม

## ไฟล์และเวอร์ชันไลบรารี

- `platformio.ini`: environment `esp32dev` และไลบรารีที่จำเป็น
- `src/main.cpp`: โค้ดทั้งหมดของเฟิร์มแวร์
- `diagram.json`: ตำแหน่งอุปกรณ์และการต่อวงจร Wokwi
- `wokwi.toml`: ตำแหน่งไฟล์เฟิร์มแวร์สำหรับ Simulator

ล็อก ESP32Servo ที่ 0.13.0 เพื่อรองรับ Arduino-ESP32 2.x ที่มากับแพลตฟอร์ม `espressif32` ทางการ
