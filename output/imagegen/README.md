# Vibecom — ภาพนำเสนอ v0.3

ภาพแนวนอน 16:9 สองภาพ สร้างผ่าน API ของ MaxPlus ด้วยโมเดล `gpt-image-2-4k`, `size=3840x2160`, `quality=high` โดยใช้ภาพเรนเดอร์ประกอบและภาพแยกชิ้นส่วนของโมเดล v0.3 เป็นภาพอ้างอิง

- [Blueprint](vibecom-blueprint-16x9-v2.png): ภาพเขียนแบบสำหรับอธิบายแนวคิดและขนาดหลัก แก้คำกำกับแกนความสูง/ความลึกให้ตรงกับโมเดลแล้ว
- [Presentation](vibecom-presentation-16x9-v1.png): ภาพพรีเซนต์ตัวหุ่นและภาพศึกษาโมเดล 3D
- [พรอมป์ต์เต็มและข้อมูลการสร้าง](vibecom-image-prompts-v1.json)

ภาพ Blueprint และภาพแยกชิ้นส่วนที่ AI วาดเป็นภาพประกอบ ไม่ใช่ drawing สำหรับผลิต ใช้ [Blender ต้นฉบับ](../../mechanical/exports/vibecom.blend), [GLB](../../mechanical/exports/vibecom.glb) และ [เอกสารโมเดล](../../mechanical/README.md) สำหรับ geometry และข้อจำกัดจริง ภาพเหล่านี้ไม่ได้แก้ไขโมเดล 3D หรือไฟล์ STL

API key ไม่ได้บันทึกในโปรเจกต์
