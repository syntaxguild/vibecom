# Vibecom — เพื่อนตัวเล็กบนโต๊ะ

[English overview](../README.md) · [ดาวน์โหลด v0.6.1](https://github.com/syntaxguild/vibecom/releases/tag/v0.6.1)

![Vibecom จากโมเดลจริง](assets/vibecom-cover.png)

Vibecom เป็นหุ่นตั้งโต๊ะที่สื่ออารมณ์ผ่านดวงตาและการหันหัว ใช้ ESP32 อ่านระยะกับการสัมผัส แล้วตอบสนองด้วยท่าทางที่ออกแบบไว้ ทำงานในเครื่องด้วย state machine ไม่ต้องใช้ LLM หรือบริการคลาวด์

มี 5 อารมณ์: Idle, Happy, Angry, Love และ Sleepy แตะครั้งเดียวเพื่อเรียกความสนใจ แตะสองครั้งเพื่อเล่น แตะค้างเพื่อแสดงความรัก และมี 4 บุคลิกให้ปรับผ่าน Serial พร้อมบันทึกค่าข้ามรีสตาร์ต

## สถานะปัจจุบัน

รุ่น **0.6.1** มีเฟิร์มแวร์ที่ build ได้ครบ 5 โปรไฟล์ มี host tests, custom chip VL53L1X สำหรับ Wokwi และโมเดลแยก 6 ชิ้น พร้อม BLEND/GLB/STL ขนาดรวม 80 × 66 × 100.8 มม.

ผ่านการตรวจการชนในคอม ทางใส่ตัวอย่าง การหมุนหัว และทางใส่หัวสกรูตามขอบเขตที่ระบุแล้ว ผู้ใช้ยืนยันว่า Wokwi เปิดชิป VL53L1X และรันได้ แต่ยังไม่ได้พิมพ์หรือประกอบกับอะไหล่จริง จึงต้องวัดหัวเสียบ ความหนาจอ horn และเดินสายจริงก่อนสั่งพิมพ์ชุดสำเร็จ ผลตรวจในคอมไม่ใช่เปอร์เซ็นต์โอกาสประกอบสำเร็จ

## คำสั่งเริ่มต้น

```sh
pio run -e esp32vibecom
pio run -e esp32sim
```

โปรไฟล์แรกสำหรับฮาร์ดแวร์อ้างอิง โปรไฟล์หลังสำหรับ Wokwi ใน VS Code อ่านวิธีต่อไฟและกราวด์ร่วมใน [Hardware](HARDWARE.md) ก่อนอัปโหลดลงบอร์ดจริง
